# eliot example sweep — scripts/example-sweep.sh
#
# One block per module in examples/src. A module with no `main` compiles to no jar and its block
# is just the `compile:` line; the true baseline is 45 of 50.
#
#   jar.md5             the byte-identity oracle for a change that must not alter output
#   jar.size            bytes of the reproducible jar
#   jar.classes         classes in the jar
#   jar.instructions    bytecode instructions over all of them — what a specialisation change moves
#   main.class          the jar's Main-Class: the synthesized entry stub, not the program
#   main.instructions   its instruction count (the same handful everywhere)
#   module.instructions the class named after the module — the program's own code
#   exit, stdout        one run, stdin /dev/null (a tty changes what the stdin-reading examples
#                       print), 60s timeout
#
# Compare two reports with:  diff <(grep -v '^#' before.txt) <(grep -v '^#' after.txt)
